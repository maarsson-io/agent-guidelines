# Changelog

All notable changes to `maarsson/agent-guidelines` will be documented in this file.

## 1.0.0 - 2026-10-06

- Initial package structure with shared guidelines and an additive Laravel Boost overlay.
- Reusable skills for Laravel/PHP development, Vue frontend development, specification-driven development, and code review.
- Support for consumer-specific maintainer profiles and project guideline indexes.
- Support for project-specific guideline and domain-skill templates with a non-overwriting initializer and optional local maintainer profile.
- CLI commands to share `.agents/skills` through Claude Code and GitHub Copilot symlinks without replacing existing content.
